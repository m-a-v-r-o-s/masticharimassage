# Mastichari Massage

Website for Konstantinos Fessaras, a mobile massage therapist working in Mastichari,
Tigaki and Marmari on Kos. Nine languages, 145 static pages, one small server in
front of them.

Rebuilt from scratch after the original WordPress site went offline. Everything on
it — the business facts, the service descriptions, the 41 client testimonials, the
certificates — was recovered from Wayback Machine captures of 2015–2018 and then
rewritten rather than transcribed.

## Running it

```bash
npm install
npm run assets     # fonts, image ladder, favicons and the OG card
npm run build      # i18n gate, then 145 pages into _site/
npm run serve      # Fastify on :8080
```

`npm run dev` builds and serves in one step. `npm run audit` walks the built output.

## What is where

```
content/               all copy, no markup
  _locales.json        the nine locales and their live/draft status
  _business.json       phone, email, hours, services, credentials - the facts
  _images.json         generated by scripts/process-images.js, never edited by hand
  testimonials.json    41 real comments, with translations for the live locales
  <locale>/site.json   every string on the site, one file per language

src/
  _data/               Eleventy data layer over content/
  _includes/           base layout and partials
  pages/               ten page templates, paginated across locales
  assets/              css, js, fonts, images
    img/_src/          image masters - derivatives are generated, not committed by hand

server/
  index.js             static serving, headers, locale negotiation, redirects, booking
  security.js          CSP, sanitisation, signed form tokens, salted IP hashing
  redirects.js         301/410 map from the old WordPress URLs
  mailer.js            booking enquiry -> Resend -> the client's inbox

scripts/
  i18n-check.js        build gate: key parity, empty strings, alt text, stale prices
  audit.js             post-build sweep of all 145 pages
  process-images.js    crops, strips EXIF, builds the AVIF/WebP/JPEG ladder
  build-fonts.js       self-hosts Inter + Source Serif 4, split by unicode-range
  build-icons.js       favicons, web manifest, Open Graph card

docs/
  LAUNCH.md            what is done, what to do before and after deploying
  CLIENT-QUESTIONS.md  the ten open questions for Konstantinos
  PENDING-IMAGES.md    the four illustrations still to generate, with prompts and seeds
```

## Decisions worth knowing before changing anything

**Copy never lives in a template.** Templates read `content/<locale>/site.json`.
Adding a string means adding it to all nine files — `npm run check` fails the build
otherwise, which is the point.

**Real locale routing, not same-URL dual-render.** Nine languages in one document
would give eight markets English metadata in search results and ship nine copies of
the text to every visitor. Ten templates generate 144 pages at build time, so the
file count costs nothing.

**Draft locales are a shipping mechanism, not a placeholder.** Dutch, Polish, Spanish
and Ukrainian are built and reachable, but `noindex`, sitemap-excluded, hidden from
the switcher, and carry a banner saying the translation is unreviewed. Flip
`"status": "live"` in `content/_locales.json` once a native speaker has read one.
Nothing else changes.

**No inline styles or scripts, anywhere.** That is what lets the CSP run without
`unsafe-inline`. `npm run audit` fails if one appears. Use a utility class.

**Prices are on request, and enforced.** The 2015 figures are stale. `i18n-check`
fails the build if a euro amount reappears in the copy, and the structured data omits
`Offer` entirely while `prices.published` is false.

**`knowsLanguage` is Greek, English and Italian.** That is what Konstantinos speaks.
It is a fact about a person and must never be derived from the set of languages the
site is published in.

**Images are never upscaled and always stripped of EXIF.** The portrait is 367px
wide and stays that way. Two of the recovered photographs carried GPS coordinates;
the processing script strips metadata and then verifies that it did.
