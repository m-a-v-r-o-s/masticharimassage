# Mastichari Massage

Website for Konstantinos Fessaras, a massage therapist working at his studio in
Mastichari, Kos, next to Ghitonia. Ten languages, 171 static pages, one small server
in front of them.

Built from scratch. The business facts, the service descriptions, the 41 client
testimonials and the certificates were all verified against archival captures of
2015–2018 and then rewritten rather than transcribed.

## Running it

```bash
npm install
npm run assets     # fonts, image ladder, favicons and the OG card
npm run build      # i18n gate, then 171 pages into _site/
npm run serve      # Fastify on :8080
```

`npm run dev` builds and serves in one step. `npm run audit` walks the built output.

## What is where

```
content/               all copy, no markup
  _locales.json        the ten locales and their live/draft status
  _business.json       phone, email, hours, services, credentials - the facts
  _images.json         generated by scripts/process-images.js, never edited by hand
  testimonials.json    42 real comments, with translations for the live locales
  <locale>/site.json   every string on the site, one file per language

src/
  _data/               Eleventy data layer over content/
  _includes/           base layout and partials
  pages/               nine page templates, paginated across locales
  assets/              css, js, fonts, images
    img/_src/          image masters - derivatives are generated, not committed by hand

server/
  index.js             static serving, headers, locale negotiation, redirects, 404 rate limit
  security.js          security headers, CSP, salted IP hashing
  redirects.js         301/410 map for legacy inbound URLs

scripts/
  i18n-check.js        build gate: key parity, empty strings, alt text, stale prices
  audit.js             post-build sweep of all 171 pages
  process-images.js    crops, strips EXIF, builds the AVIF/WebP/JPEG ladder
  build-fonts.js       self-hosts Inter + Source Serif 4, split by unicode-range
  build-icons.js       favicons, web manifest, Open Graph card

docs/
  LAUNCH.md            what is done, what to do before and after deploying
  CLIENT-QUESTIONS.md  the ten open questions for Konstantinos
  PENDING-IMAGES.md    the four illustrations still to generate, with prompts and seeds
```

## Decisions worth knowing before changing anything

**Copy never lives in a template.** Templates read `content/<locale>/site.json`.
Adding a string means adding it to all ten files — `npm run check` fails the build
otherwise, which is the point.

**Real locale routing, not same-URL dual-render.** Ten languages in one document
would give nine markets English metadata in search results and ship ten copies of
the text to every visitor. Real locale routing generates 180 pages at build time, so
the file count costs nothing.

**Draft locales are a shipping mechanism, not a placeholder.** Dutch, Polish, Spanish
and Ukrainian are built and reachable, but `noindex`, sitemap-excluded, hidden from
the switcher, and carry a banner saying the translation is unreviewed. Flip
`"status": "live"` in `content/_locales.json` once a native speaker has read one.
Nothing else changes.

**No inline styles or scripts, anywhere.** That is what lets the CSP run without
`unsafe-inline`. `npm run audit` fails if one appears. Use a utility class.

**Prices are on request, and enforced.** The 2015 figures are stale. `i18n-check`
fails the build if a euro amount reappears in the copy, and the structured data omits
`Offer` entirely while `prices.published` is false.

**`knowsLanguage` is Greek, English, Italian, French, German and Russian.** That is
what Konstantinos speaks. It is a fact about a person and must never be derived from
the set of languages the site is published in.

**Images are never upscaled and always stripped of EXIF.** A master narrower than a
ladder step is served at its own native width rather than interpolated up to the
step. Two of the recovered photographs carried GPS coordinates; the processing
script strips metadata and then verifies that it did.

**The portrait master is cropped, and the crop is load-bearing.** The photograph is
a treatment-room shot in which a client is visible under Konstantinos's hands. The
crop box in `scripts/process-images.js` keeps him and excludes her. Widening it
would publish a client's photograph on a business page she never sat for.
